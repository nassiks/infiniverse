# YOUR UNIVERSE — упорядоченный прототип

Переработка переданных `index(2).html` и `scene(1).js` без изменения основной логики.

## Запуск

Рекомендуется запустить локальный веб-сервер из корня папки проекта:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000/ . Для ES-модулей не рекомендуется запускать `index.html` непосредственно через `file://`.

## Структура

```text
index.html                         HTML-интерфейс
styles/main.css                   оформление, анимация, адаптивность
scripts/scene.js                  WebGL-сцена, камера, переход, поиск, UI
scripts/world.js                  генерация пространственных координат
scripts/shaders.js                WebGL-шейдеры планет
data/planets.js                   загрузка 100 планет через window.PLANETS
data/planets.json                 те же тестовые данные в JSON
assets/galaxy/galaxy_core.png    внешняя художественная галактика
assets/galaxy/nebula_haze.png    фоновая туманность
assets/galaxy/nebula_front.png   передняя туманность
assets/planets/planet_texture_atlas.webp  атлас текстур 10 × 10
assets/background/stars_and_distant_galaxies.webp  дополнительный фон (не подключён)
```

## Поведение

- Сохраняется переход из общего вида галактики к 100 3D-планетам.
- Генерация координат и минимальный зазор планет вынесены в `scripts/world.js`.
- Поиск по никам, карточки и смена активности планет — в `scripts/scene.js`.
- Космические звёзды в переданном `scene(1).js` всё ещё рисуются Canvas: это сохранено намеренно, чтобы рефакторинг не изменил поведение. В `assets/background/` вложена альтернативная текстура для будущего перехода на статичный фон.
- Демонстрационное изменение активности не сохраняется после перезагрузки страницы.

## Примечание

Файлы изображений и тестовые данные восстановлены из предыдущей сборки проекта. Работа на устройстве требует браузера с WebGL. Координаты генерируются воспроизводимо, но могут измениться при перестановке входных данных, поэтому для будущего каталога пользователей их следует сохранять в базе.
