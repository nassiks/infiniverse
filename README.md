# INFINIVERSE

Интерактивная галактика GENESIS-01: 100 планет в 3D, поиск по никнейму, имени и ID, экран персональной планеты.

## Запуск

```bash
python -m http.server 8000
```

Открой http://localhost:8000/ (через HTTP, не `file://`).

## UX/UI-редизайн

- Отдельный контрастный хедер с SVG-логотипом, настройками и поиском.
- Главная композиция с названием галактики, статистикой и явным действием «Исследовать галактику».
- Внутри — отдельная кнопка «К галактике», масштаб, 3D и планеты; масштабирование больше не отправляет на другой уровень.
- Поиск доступен всегда: ник, имя, ID; результаты показывают название; диалог имеет Escape, trap focus и возврат фокуса.
- Инструкция о создании планеты доступна в отдельном окне. **Аккаунт Instagram не указан:** ссылку нельзя добавлять, пока не будет точного адреса.
- Убрана демонстрационная кнопка изменения подписки: статус — только отображаемые данные.
- Мобильная раскладка с читаемыми размерами, touch-action только для WebGL.
- Анимация включена по умолчанию; отключённая анимация корректно переключает режимы. Учитывается `prefers-reduced-motion`.
- Подписи показываются по мере приближения; ближние планеты и ники скрывают дальние подписи.
- Состояния WebGL context loss и ошибки загрузки атласа видимы пользователю.
- Отдельный favicon, SEO и og:title/description. CSS заменён цельной системой стилей без накопленных переопределений.

## Структура

- `index.html` — семантическая разметка и панель управления;
- `styles/main.css` — единая система стилей;
- `scripts/scene.js` — 3D-сцена, поиск, камера, UI;
- `scripts/shaders.js` — WebGL-шейдеры;
- `scripts/world.js` — координаты планет;
- `data/planets.js` / `data/planets.json` — прототипные данные;
- `assets/branding/` — логотип и favicon.

## Ограничения прототипа

Это статический сайт без сохранения подписок или пользовательских изменений на сервере. Для реальной регистрации планеты нужны подтверждённая ссылка на Instagram, процедура модерации/добавления планеты и серверная логика. Требуется проверка в браузерах и на iOS/Android перед слиянием с `main`.
