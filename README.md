# INFINIVERSE — интерактивная галактика

Статический прототип: внешний вид галактики на художественных слоях, 100 WebGL-планет внутри.

## Запуск

Запусти из корня проекта:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000/. ES-модули не следует открывать через `file://`.

## Устройство

- `index.html` — разметка интерфейса.
- `styles/main.css` — стили, адаптивность, анимации.
- `scripts/scene.js` — WebGL-рендер, камера, переходы и UI.
- `scripts/shaders.js` — перспективная проекция и освещение планет.
- `scripts/world.js` — координаты только для новых планет.
- `data/planets.json` — исходные данные 100 планет, включая сохранённые `world` и `radius`.
- `data/planets.js` — статическая копия этих данных, загружается страницей через `window.PLANETS`.
- `assets/background/stars_and_distant_galaxies.webp` — звёзды и далёкие галактики, изображение с лёгкой CSS-анимацией.
- `assets/galaxy/` — графические слои галактики.
- `assets/planets/` — атлас текстур планет 10 × 10.

## Что исправлено в этой ветке

1. Убран Canvas-рендер 800 процедурных звёзд. Используется фоновый WebP + CSS.
2. Вместо ручного `gl_Position(..., w=1)` используется перспективная матрица, корректный depth test и near-plane clipping.
3. Обзорная камера находится перед всеми 100 планетами.
4. Цвет ободка неактивных планет тоже нейтральный.
5. Координаты и радиусы существующих 100 планет сохранены в данных: добавление новых объектов не перемещает старые.

**Важно:** если добавляешь новую планету, нужно сохранить назначенные `world` и `radius` в обоих файлах данных. Сейчас у проекта нет сервера/базы данных для автоматического сохранения. Демонстрационное изменение активности через кнопку не сохраняется после перезагрузки.

## Дальнейшее развитие

Выделить управление камерой и интерфейсом из `scene.js`, убрать дублирование JSON/JS через шаг сборки или загрузку JSON, добавить тесты, обработку WebGL context loss и хранение планет на сервере.

## Интерактивное управление

- Камера поиска останавливается на безопасном расстоянии, рассчитанном по радиусу планеты.
- На телефоне жест двумя пальцами приближает WebGL-сцену, а не страницу; один палец перемещает камеру.
- Поиск работает и с внешнего обзора, и изнутри галактики: вход и перелёт выполняются последовательно.
- Над видимыми 3D-планетами отображаются Instagram-ники.
- Кнопка «Обзор галактики» удалена. Выход через меню или отдаление «−».
- Анимация входа усилена свечением и радиальными лучами («гиперпрыжок»).
